# wanda-support

Public support and legal pages for Wanda mobile apps.

- `index.html` — app selector and contact
- `privacy.html` / `terms.html` — Wanda Staff
- `customer-support.html` — Wanda customer support
- `customer-privacy.html` — Wanda customer privacy notice
- `customer-terms.html` — Wanda customer terms
- `customer-delete-account.html` — external customer account-deletion request path required by Google Play
